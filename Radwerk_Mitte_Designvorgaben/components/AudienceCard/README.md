# AudienceCard

Zielgruppen-Kachel mit Foto, Titel, einem Satz und Textlink – die Weiche nach JobRad-Muster.

- Foto oben, Seitenverhältnis 16:9, Radius über die Karte (`radius-md`), echtes Motiv aus Kassel oder Göttingen.
- Titel `h3`, Text max. ein Satz in `ink-muted`, Link in `interactive` mit Pfeil.
- Die Arbeitgeber-Kachel steht immer zuerst und darf mit 2 px `radblau` hervorgehoben werden.
- Karten liegen auf `surface-soft` mit `shadow-card`.
