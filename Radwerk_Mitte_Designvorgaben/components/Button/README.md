# Button

Pill-Buttons in drei Rangstufen: primär (Radblau), akzent (Koralle), sekundär (weiß mit Rand).

- **Primär** `radblau` + weißer Text: die eine Hauptaktion einer Sektion.
- **Akzent** `koralle` + `nachtblau`-Text: zweite konkrete Handlung, höchstens einmal pro Bildschirm. Nie weißer Text auf Koralle.
- **Sekundär** `surface-card` mit `border-strong`: alle weiteren Aktionen.
- Mindesthöhe 44 px, Typo-Stil `button`, Radius `radius-pill`, Fokusring 3 px `interactive`.
- Beschriftung als Verb + Objekt: „Angebot anfragen“, „Rate berechnen“, „Status prüfen“.
